# ✨ White Aura | Modern Dental Care & Aesthetics

A **premium, fully responsive, and modern dental clinic & aesthetics website** built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **shadcn/ui** components. 

The website provides an elegant, trustworthy, and seamless experience for patients to explore treatments, learn about specialized dentists, check clinic hours, and schedule appointments with ease.

---

## 🌟 Highlights & Features

- **📱 Fully Responsive Design** – Pixel-perfect layouts optimized across all modern mobile devices, tablets, and ultra-wide desktop monitors.
- **🦷 Comprehensive Service Catalog** – Categorized presentation of dental procedures:
  - *General Dentistry* (Regular cleanings, cavity fillings, digital oral exams)
  - *Cosmetic Dentistry & Veneers* (Teeth whitening, porcelain veneers, smile makeovers)
  - *Restorative Care & Implants* (Crowns, bridges, dental implants, root canal therapy)
  - *Pediatric & Family Dentistry* (Gentle, child-friendly preventive care)
- **📅 Interactive Appointment Booking** – Intuitive appointment inquiry form with date/time preference selection and instant service filtering.
- **🚨 24/7 Emergency Dental Care** – Dedicated hotline section for urgent toothaches, dental trauma, and same-day emergency visits.
- **📍 Rich Location & Contact Information** – Direct click-to-call (`tel:`) and click-to-email (`mailto:`) integration, navigation directions, and office hours overview.
- **⭐ Patient Trust & Social Proof** – Verified patient testimonials, success metrics, clinic milestones, and practitioner profiles.
- **⚡ Modern Architecture** – Powered by Next.js 15 App Router with high performance, optimized font loading, and SEO metadata.

## 📦 Getting Started & Installation

### Prerequisites

Ensure you have **Node.js** (v18.18 or higher) installed on your system.

### 1. Clone or Open the Repository

```bash
git clone https://github.com/pawantech12/brightsmile-dental-website.git
cd White-Aaura
```

### 2. Install Dependencies

Using `npm`:
```bash
npm install
```

Or using `pnpm`:
```bash
pnpm install
```

### 3. Run Development Server

```bash
npm run dev
# or
pnpm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser to view the website.

### 4. Build for Production

```bash
npm run build
npm run start
```

## 🌐 Deployment

The application is fully compatible with [Vercel](https://vercel.com/):

1. Push your repository to GitHub / GitLab / Bitbucket.
2. Import the repository into the **Vercel Dashboard**.
3. Deploy directly — Next.js App Router settings will be automatically detected.
